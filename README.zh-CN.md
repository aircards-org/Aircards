**发现、创作与分享卡面。**

AirCards 汇集精选卡面和创作者投稿，帮助你为自己设备上的 Apple 钱包卡片找到喜欢的设计。

## 探索、创作与分享

- **浏览卡面**：探索卡面图库，下载喜欢的图片。
- **制作卡面**：使用在线工作台搭配模板、编辑构图并导出图片。
- **分享作品**：提交自己的作品，通过审核后与社区分享，也可以发现其他创作者的设计。
- **多语言浏览**：支持简体中文、繁体中文、英语、日语和韩语。

## 开始使用

1. 打开 [AirCards 官网](https://aircards.org/zh-CN/)。
2. 浏览图库，或进入[卡面工作台](https://aircards.org/zh-CN/upload/)创作。
3. 下载卡面图片，按照[使用指南](https://aircards.org/zh-CN/guide/)完成后续操作。

AirCards 是卡面素材与创作网站。**AirCard** 是独立项目，用于在受支持设备上修改钱包卡片的显示画面。设备兼容性与使用方法请以使用指南和 AirCard 自身文档为准。

## 反馈与联系

对网站使用有疑问、遇到问题或有功能建议？欢迎用中文或英文[提交 Issue](https://github.com/aircards-org/aircards/issues/new/choose)。

提交 Issue 需要 GitHub 账号。AirCard 安装、设备兼容性和钱包修改问题，请通过[使用指南](https://aircards.org/zh-CN/guide/)中的对应平台项目反馈。

账号问题、隐私或安全问题、素材更正或撤下申请，请联系 **contact@aircards.org**。请勿在公开 Issue 中提交卡号、账号凭据或其他私人信息。
